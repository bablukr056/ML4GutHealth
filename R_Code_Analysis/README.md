## Scripts — Figures & Diversity Analysis (R)

- **`Figure_Generation_Code_MainText_Supplementary.R`** — Generates all main-text and supplementary figures for the manuscript.
- **`alpha_beta_diversity_figures.R`** — Generates alpha and beta diversity comparison figures across groups.
- **`alpha_diversity_code.R`** — Computes alpha diversity metrics (e.g., Shannon, Chao1) from the abundance data.
- **`auc_vs_disease_sample_size.R`** — Analyzes and plots the relationship between AUC performance and per-disease sample size.
- **`batch_effect_analysis.ipynb`** — Notebook for evaluating and visualizing batch effects across studies.
- **`beta_diversity_plot.R`** — Generates beta diversity ordination plots (e.g., PCoA) across groups.
- **`mmuphin_batch_correction.R`** — Runs MMUPHin batch correction and evaluates it with PERMANOVA.
- **`plot_combined_clr_tss_clean.R`** — Generates combined CLR vs. TSS comparison plots.
- **`plot_pcoa_batch_correction_comparison.R`** — Compares PCoA ordinations before and after batch correction.

**Note:** For instructions on how to run each script, refer to the usage guidelines provided inside the script itself.
